# Track Catalog

- `oval`: easy rounded rectangle for initial debugging.
- `s_curve`: alternating medium-speed bends.
- `kidney`: asymmetric loop with mixed-radius corners.
- `chicane`: tests rapid direction changes.
- `hairpin`: includes a tight slow corner and awkward exit.
- `sweepers`: wider, faster flowing corners.
- `stop_go`: straights into slower corners.
- `club`: compact club-circuit style mixed layout.
- `mini_monaco`: narrow technical circuit with repeated transitions.
- `technical`: original polygonal hard track, kept as a challenge case.
